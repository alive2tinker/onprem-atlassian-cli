# Atlassian Cross-Product Research

Use this skill when the user asks for an answer that likely needs both Jira issues and Confluence pages.

## Workflow

1. Start from the user's strongest anchor: issue key, project, component, release, incident, service, page title, or space.
2. Search Jira for implementation, incidents, decisions, and current work.
3. Search Confluence for requirements, design docs, runbooks, meeting notes, and release pages.
4. Reconcile the sources into a concise answer with explicit references.
5. Separate confirmed facts, likely inferences, and unresolved questions.

## Guardrails

- Prefer source-backed summaries over broad speculation.
- Ask before writing to either Jira or Confluence.
