# Confluence Page Maintenance

Use this skill when the user asks to clean up, audit, update, label, reorganize, or de-duplicate Confluence content.

## Workflow

1. Search the relevant space, parent page, label set, or topic.
2. Compare pages by title, last updated date, owner, labels, and content overlap.
3. Recommend archive, merge, update, relabel, or owner-review actions.
4. Make changes only after explicit user instruction.

## Guardrails

- Do not delete or archive pages unless the user explicitly asks and the action is supported.
- Keep recommendations concrete and reversible where possible.
