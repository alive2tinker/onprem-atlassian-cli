# Confluence Knowledge Synthesis

Use this skill when the user asks to understand a topic spread across Confluence pages.

## Workflow

1. Search broadly enough to capture canonical and related pages.
2. Read the likely source-of-truth pages first, then supporting pages.
3. Distinguish facts, open questions, outdated information, and inferred relationships.
4. Summarize with citations to page titles and, when available, page links or IDs.

## Guardrails

- Do not collapse conflicting sources into a false certainty.
- Call out stale pages and recommend owner review when needed.
