# Atlassian Reporting

Use this skill for recurring or one-off reports built from Jira and Confluence.

## Workflow

1. Define report scope: project, team, date range, release, incident, component, or space.
2. Pull Jira issues for work state and Confluence pages for narrative context.
3. Group findings into completed work, in-progress work, blockers, risks, decisions, and next actions.
4. Keep issue keys and page titles visible so the report is auditable.
5. Draft a Confluence-ready version if requested.

## Guardrails

- Do not post reports without explicit instruction.
- Mention missing source coverage, especially unavailable Confluence configuration.
