# Confluence Page Authoring

Use this skill when the user wants a Confluence page drafted, created, or updated.

## Workflow

1. Clarify or infer the page purpose: doc, decision record, meeting notes, runbook, release notes, RCA, or project brief.
2. Search for existing related pages to avoid duplicates.
3. Draft structured content with headings that match the space's style.
4. Create or update the page only when the user asks for that write.
5. Verify page title, space, parent, and update result.

## Guardrails

- Confirm before overwriting large sections.
- Preserve existing page structure unless the user asks for a rewrite.
- Keep internal claims traceable to Jira issues or existing Confluence pages where possible.
