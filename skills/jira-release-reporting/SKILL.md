# Jira Release Reporting

Use this skill for release notes, fix versions, deployment summaries, shipped work, or release readiness.

## Workflow

1. Identify the project and version, date range, deployment label, or release train.
2. Search Jira for completed, in-progress, and unresolved issues in scope.
3. Group changes by feature, bug fix, operational task, risk, and owner.
4. Call out unresolved blockers, late changes, missing QA, and rollback concerns.
5. If requested, draft Confluence-ready release notes.

## Output

Prefer a concise executive summary followed by grouped issue keys.
