# Jira Incident Management

Use this skill when the user asks about incidents, outages, RCAs, SEVs, hotfixes, or operational follow-ups in Jira.

## Workflow

1. Find incident-related Jira issues by key, project, component, label, priority, date, or text.
2. Read recent comments, linked issues, subtasks, and current status.
3. Summarize impact, timeline signals, current owner, mitigations, open actions, and next update needed.
4. When asked, draft updates or follow-up tasks.

## Guardrails

- Preserve factual uncertainty; do not invent timelines or root causes.
- Confirm before posting incident updates or closing follow-up items.
