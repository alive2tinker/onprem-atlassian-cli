# Confluence Runbooks

Use this skill for runbooks, SOPs, troubleshooting, operational checklists, and support playbooks.

## Workflow

1. Search for existing runbooks or related incident pages.
2. Structure runbooks around symptoms, impact, prerequisites, diagnosis, mitigation, escalation, rollback, and verification.
3. Link related Jira incidents, known problems, services, dashboards, and owners when available.
4. Create or update Confluence only when requested.

## Guardrails

- Avoid inventing commands, contacts, URLs, or operational steps.
- Flag any missing verification or rollback steps.
